# 寻仙资源资料库

一个整理、检索与阅读《寻仙》游戏道具、宠物和称号内容的非官方资料库。

一个称号因何而来，一只灵兽由什么道具唤出，一件旧日礼包中又藏着什么？这里希望把散落在游戏资源中的物、灵与称号重新整理起来，让每一条仍有迹可循的仙途都更容易被找到。

> 物有来处，灵有所归，旧迹仍可寻。

## 在线访问

[xunxian.wiki](https://xunxian.wiki)

## 收录内容

资料库目前可以检索 50,194 条道具、1,255 条宠物资料和 2,953 个称号，内容包括：

- 道具名称、分类、品质、购买价格与出售价格；
- 道具说明、使用效果和可能获得的宠物、坐骑或称号；
- 侍宠、灵兽坐骑、道具坐骑、系统坐骑和其他特殊配置；
- 宠物模型、外形、资料备注与基础属性；
- 宠物和坐骑的获得道具，以及能够确认的坐骑技能；
- 称号说明、获得条件与相关道具；
- 道具、宠物、称号与任务之间能够确认的联系。

并不是每条资料都拥有完整说明。有些旧配置只留下了名称或编号，有些道具与宠物之间也缺少足够证据。遇到这种情况，资料库会明确显示为空或待确认，不凭名称猜测结果。

## 可以怎样寻找

- **查找道具**：输入道具名称，或在普通道具与任务道具之间筛选。
- **查找宠物**：寻找侍宠、灵兽坐骑、道具坐骑、系统坐骑、炮台和其他特殊配置。
- **查找称号**：查看称号说明、获得条件和相关道具。
- **顺着获得关系浏览**：从宠物找到对应的蛋或道具，也可以从道具继续查看它会获得什么。
- **前往相关任务**：资料中如果存在明确的任务联系，可以直接打开任务资料页继续阅读。

## 为什么整理

《寻仙》的世界不只存在于任务和剧情中。一枚印记、一颗宠物蛋、一件节日礼包，甚至一个很少再见到的称号，都记录着某个版本、某场活动或一段玩家共同经历过的时光。

随着版本变化，许多物品已经很难再次遇见，旧有的获得方式和说明也逐渐散落。这个资料库希望为这些内容留下一份方便查找的索引。它不是交易价格指南，也不替玩家规划养成路线；更像是一册可以慢慢翻阅的寻仙旧物录。

## 关于资料

资料来自本地游戏资源的整理。页面尽量保留原有名称和说明，并把能够确认的道具、宠物、坐骑、称号与任务关系连接起来。

同一个数字在不同资料中可能代表完全不同的东西，因此资料库不会仅凭编号建立关系。无法确认的字段不会被强行解释，推测内容也不会当作官方事实展示。

原始游戏资料不会在本仓库中提供或上传。
