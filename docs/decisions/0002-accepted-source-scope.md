# ADR 0002：接受当前资料集为项目完整输入范围

状态：已采用  
日期：2026-07-28

## 背景

全量清点发现本地资料有 832 个文件，首期 40 个重点来源全部存在，但 `index_list.txt` 还引用了 578 个未随资料提供的文件，其中许多属于服务器脚本和其他未取得的安装包范围。

## 决策

维护者确认现有 `original_data/` 就是本项目可获得的全部资料。因此：

- 当前资料集视为首期项目的完整输入范围；
- 578 个索引差异继续保留在质量报告中，不伪装成“索引完全覆盖”；
- 索引差异不再阻塞道具、宠物、骑乘和称号开发；
- 40 个重点来源缺失、文本无法解码或输入校验值变化仍属于阻塞问题；
- 未来若取得补充资料，必须重新清点并以新构建 ID 重建。

该决定只改变项目验收范围，不修改任何原始文件，也不改变来源证据。
