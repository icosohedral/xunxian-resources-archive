# ADR 0001：复合资源身份与任务站边界

状态：已采用  
日期：2026-07-28

## 决策

所有本地资源使用 `(resource_kind, resource_id)` 作为身份。普通道具、任务道具、宠物、称号和骑乘配置属于独立编号空间。

任务事实仍由现有任务资料库维护。本项目不复制任务数据库，只接收符合 JSON Schema 的轻量关系文件，并通过任务 ID 链接到 `https://quests.xunxian.wiki/quests/{quest_id}`。

## 原因

不同系统会复用相同数字 ID；只用数字会产生错误合并。复制任务数据库则会造成事实过期和双重维护。复合身份与版本化交换契约同时解决这两个问题。
