# 宠物与坐骑页面分类

本分类用于网站检索和展示，不宣称是游戏官方分类。原始资料没有统一的
“侍宠／灵兽坐骑／道具坐骑”字段，因此必须依据宠物与骑乘配置的明确关系、
获得道具关系和少量名称标记进行分层。

## 一级分类

| 分类键 | 页面名称 | 判定规则 |
|---|---|---|
| `servant_pet` | 侍宠 | 宠物记录没有明确的 `uses_ride` 关系。 |
| `spirit_mount` | 灵兽坐骑 | 宠物记录通过 `ride_id` 建立了 `uses_ride` 关系。 |
| `item_mount` | 道具坐骑 | 骑乘配置没有对应宠物，但存在道具的 `grants_ride` 关系。 |
| `system_mount` | 系统／场景坐骑 | 没有宠物和获得道具，名称明确指向副本、情景、活动、NPC、多人骑乘、船只或特殊系统用途。 |
| `turret` | 炮台 | 没有宠物和获得道具，名称明确包含炮、火炮或炮台。 |
| `interaction` | 互动配置 | 没有宠物和获得道具，名称明确表示背、托、顶等角色互动动作。 |
| `unclassified` | 其他 | 暂时没有足够证据归入以上类别。 |

当前资料构建结果共显示 1255 条：侍宠 435、灵兽坐骑 380、道具坐骑
128、系统／场景坐骑 47、炮台 27、互动配置 6、其他 232。

## 去重与隐藏规则

- 已经被宠物使用的骑乘配置不在宠物检索结果中作为独立条目重复展示；
  仍可从宠物详情中的骑乘配置和坐骑技能链接访问。
- 名称明确包含 `(x)`、`（x）`、`测试` 或 `占位` 的独立骑乘配置默认隐藏。
- 宠物、骑乘配置和道具继续使用各自原始编号空间，页面合并不改变数据身份。
- 分类依据不足时必须进入“其他”，不能仅凭相似名称强行建立宠物关系。

## 道具坐骑名称

- 道具使用效果直接指向骑乘配置时，优先采用获得道具的玩家可读名称。
- 名称仅有期限、试用、赠品、绑定或限时后缀差异时，去掉这些后缀后作为
  坐骑名称；原骑乘配置名保存在“内部配置名”。
- 多个不同玩家名称共用同一骑乘配置时，不强行选择其中一个；配置标题维持
  原名，并在“玩家名称”中列出全部已确认名称。
- 名称中明确包含占位标记或装饰性占位文本的道具不参与名称选择。

## 搜索行为

- “道具”只搜索普通道具和任务道具。
- “宠物”搜索去重后的宠物、灵兽坐骑和独立坐骑，并提供上述一级分类。
- “称号”只搜索称号。
- 切换顶部标签时不继承上一类的搜索关键词或分类条件。
