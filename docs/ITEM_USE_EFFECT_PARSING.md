# 道具使用效果解析

本项目不根据道具名称猜测效果。`mb/item/item_use.txt` 中的效果参数只有在能
通过固定的类型语义和官方资料表交叉验证时，才会生成“详细效果”；否则保留原始
效果编号、类型、参数和备注，等待后续确认。

全部 162 个实际使用类型及类型 `3`、`5`、`10`、`18`、`40` 的参数分析见
[`ITEM_USE_TYPES.md`](ITEM_USE_TYPES.md)。

## 当前覆盖

以最近一次全量构建为准：

- 共有 18,150 个被道具实际引用的唯一效果。
- 7,244 个效果有可读的详细说明。
- 2,570 个效果有宠物、骑乘配置或称号实体链接。
- 去重后共有 9,814 个效果完成详细解析或实体链接，覆盖率 54.1%。
- 数据库共有 7,330 条详细效果记录：风物志 2,536、外观 2,431、普通及猎魂
  礼包 1,006、状态数组 473、状态组 378、战灵技能 313、数值参数 193。

精确数量和缺失示例以 `reports/build_summary.json` 为准。

## 尚未确认

以下高频类型仍缺少可验证的统一参数语义：

- `3 / 537`、`3 / 1367` 等脚本礼包：编号不对应 `item_rand.txt`，礼包内容可能
  由脚本或未提供的服务端表控制。
- `3 / 2139` 等任务脚本效果：只能与任务 ID 或脚本事件轻量链接，不复制任务
  数据库，也不将脚本编号解释为奖励编号。
- `92` 仙诀、`18` 附魔和部分 `5` 技能道具：虽然原始备注常含名称，但当前参数
  与候选资料表不能稳定一一对应。
- 部分状态、风物志和外观编号在现有资料中没有目标行。构建报告会保留编号示例，
  不用相似名称补齐。

新增规则时必须加入合成资料测试和至少一个真实资料抽查，确保编号空间不会串用。
