# 寻仙资源存档：当前网页设计说明

> 本文记录当前网站已经落地的页面设计与交互规则，作为后续修改、验收和跨项目对齐的直接依据。  
> 文档基于 2026-07-29 的实际实现整理；通用原则另见
> [`GENERAL_DESIGN_GUIDELINES.md`](GENERAL_DESIGN_GUIDELINES.md)。

## 1. 产品定位

网站定位为一个可检索、可追溯、适合长期阅读的《寻仙》资料卷宗。

核心气质：

- 清晰、克制、有阅读感；
- 以“档案、卷宗、印记”为视觉语汇；
- 使用楷体表现东方仙侠气质，使用无衬线字体保证功能信息清晰；
- 使用等宽字体区分编号、数量、英文眉题和技术字段；
- 不使用渐变、玻璃拟态、大圆角或大面积阴影；
- 装饰只用于建立信息层级，不压过资料本身。

页面最强视觉重点是资源名称或资源概况主文案。朱砂红只用于名称、印记和关键状态，避免整页出现多个同等强度的重点。

## 2. 页面结构

### 2.1 全局结构

桌面端采用“顶部品牌 + 资源标签 + 左侧索引 + 右侧卷宗”的结构：

```text
┌──────────────────────────────────────────────┐
│ 寻  寻仙资源存档                              │
├──────────────────────────────────────────────┤
│ 道具 │ 宠物 │ 称号 │ 任务 │ 音乐                   │
├───────────────┬──────────────────────────────┤
│ 分类索引       │ 资源详情／搜索空状态          │
│ 搜索与分类     │                              │
│ 15 条目录      │                              │
│ 分页           │                              │
└───────────────┴──────────────────────────────┘
```

资源概况页不显示左侧索引，正文使用单栏布局。

### 2.2 尺寸

| 区域 | 当前规则 |
|---|---|
| 顶部品牌栏 | 最小高度 `72px`，左右内边距 `24px` |
| 顶部资源标签 | 最大宽度 `1080px`，页面两侧至少保留 `1rem` |
| 主工作区 | 最大宽度 `1440px`，页面两侧至少保留 `1rem` |
| 左侧索引 | `290–370px` |
| 右侧正文 | 占据剩余宽度 |
| 卷宗正文 | 最大宽度 `900px` |
| 正文水平留白 | `clamp(2rem, 8vw, 7rem)` |
| 主工作区最小高度 | `calc(100vh - 210px)` |

### 2.3 页面内容

顶部共有五个同形标签：

1. 道具；
2. 宠物；
3. 称号；
4. 任务；
5. 音乐。

任务和音乐为外部网站入口，各标签下方显示各自数量。资源概况不占用顶部标签；
访问根地址或点击左上角品牌时，默认显示资源概况页。

资源概况页只保留：

- 英文眉题 `A TRACEABLE RESOURCE ARCHIVE`；
- 主文案；
- 朱砂色引导文案；
- 右侧低对比度大型“录”字背景。

资源详情按照资料类型显示：

- 资源名称与编号；
- 概览；
- 道具说明；
- 使用效果；
- 获得道具；
- 坐骑技能；
- 关联任务。

不存在或不适用的栏目不会虚构内容；需要保留栏目时，使用统一的虚线空状态。

- 当前没有常规卡片阴影，`--shadow` 为 `none`。

## 4. 字体系统

### 4.1 字体栈

当前页面明确划分展示、正文和数据三套字体。

```css
--display: "LXGW WenKai", "STKaiti", "KaiTi", serif;
--body: "PingFang SC", "Noto Sans SC", "Microsoft YaHei", sans-serif;
--utility: "SFMono-Regular", Consolas, "Liberation Mono", monospace;
```

| 字体角色 | 首选字体 | 回退字体 | 使用目的 |
|---|---|---|---|
| 展示字体 | `LXGW WenKai` | `STKaiti`、`KaiTi`、`serif` | 品牌、主标题、资源名称、章节标题、说明正文和印记 |
| 正文字体 | `PingFang SC` | `Noto Sans SC`、`Microsoft YaHei`、`sans-serif` | 表单、按钮、字段、导航和常规界面文字 |
| 数据字体 | `SFMono-Regular` | `Consolas`、`Liberation Mono`、`monospace` | 英文眉题、编号、数量、页码和技术元数据 |

### 4.2 字体加载现状

当前项目**没有通过网络或本地静态文件加载 Web Font**。

这意味着：

- 设备已安装 `LXGW WenKai` 时，展示文字使用霞鹜文楷；
- macOS 通常会优先使用 `PingFang SC` 和 `SFMono-Regular`；
- 未安装霞鹜文楷时，展示字体依次回退到 `STKaiti`、`KaiTi` 和系统衬线字体；
- Windows 正文通常回退到 `Microsoft YaHei`，数据字体通常回退到 `Consolas`；
- 不同设备上的字宽、换行位置和楷体字形可能略有差异。

全局设置 `font-synthesis: none`，浏览器不会擅自合成不存在的粗体或斜体字形。

若未来要求所有平台呈现完全一致，应在确认字体授权后提供 `woff2` 文件，并使用 `@font-face` 自托管；在此之前不能假定所有访客都能看到霞鹜文楷。

### 4.3 字号变量

浏览器根字号按默认 `16px` 计算。

| 变量 | 当前值 | 约合像素 | 用途 |
|---|---:|---:|---|
| `--font-page-title` | `clamp(1.75rem, 3vw, 2.625rem)` | `28–42px` | 资源名称、概况主标题、搜索空状态标题 |
| `--font-section-title` | `1.4375rem` | `23px` | 卷宗章节标题 |
| `--font-card-title` | `1rem` | `16px` | 列表名称、卡片标题、空状态 |
| `--font-body-copy` | `1rem` | `16px` | 道具说明和效果正文 |
| `--font-control` | `0.8125rem` | `13px` | 表单、按钮、字段值和操作 |
| `--font-meta` | `0.625rem` | `10px` | 标签、分类、关系说明 |
| `--font-data` | `0.6875rem` | `11px` | 编号、页码和技术字段 |
| `--leading-copy` | `2` | `32px`（16px 字号时） | 楷体长说明正文 |

## 5. 形状、边框与间距

### 5.1 形状

- 页面和主要卡片以方角为主；
- 普通区域使用 `1px solid` 边框；
- 当前目录项使用左侧 `4px` 朱砂色条；
- 获得道具卡片使用顶部 `3px` 朱砂色条；
- 未解析或空内容使用虚线边框；
- 印记和章节序号使用方形描边，不使用圆形图标底。

### 5.2 间距

页面以约 `4px` 为基础节奏：

- 紧密文字间距：`0.2–0.35rem`；
- 卡片内部间距：`0.65–1rem`；
- 表单和卡片组间距：`0.6–0.75rem`；
- 章节上下间距：`2rem`；
- 页面正文上下留白：`2–4.5rem`；
- 资源概况首屏顶部留白：`4–8rem`。

章节标题与所属内容距离小于章节与上一部分的距离。

## 6. 核心组件

### 6.1 品牌栏

- 白纸色背景与强分隔线；
- “寻”字使用深青底、浅纸色文字，并旋转 `-2deg`；
- 网站版本紧跟品牌名称显示，当前为 `v1.0.4`；
- 称号检索支持按上级分类或具体称号分组筛选；上级分类名称属于资料库归纳，并在界面中明确说明；
- 页头右侧提供“关于网站”，以原生对话框展示作者、维护者、项目仓库和特别鸣谢；
- 品牌栏右侧显示按中国时区统计的“今日来访”匿名浏览器数量；
- 同一浏览器同一天只计一次，访问统计存入独立数据库，不写入资源目录；
- 右侧不显示宣传语。

### 6.2 顶部资源标签

- 桌面端五等分；
- 每个标签包含分类单字、名称和数量；
- 当前标签使用深纸色背景与底部 `3px` 朱砂线；
- 悬停时使用深纸色背景和青玉绿文字；
- 任务与音乐保持相同外观，但在新标签页打开外部网站；
- 不显示“外链”字样。

### 6.3 搜索与筛选

- 左侧标题按当前标签显示为“道具索引”“宠物索引”或“称号索引”；
- 搜索框不显示外置字段标题和快捷键提示，按页面显示“输入道具名称”“输入宠物名称”或“输入称号名称”；
- 道具、宠物和称号拥有相互独立的检索入口；
- 道具可筛选“普通道具”和“任务道具”；
- 宠物可按侍宠、灵兽坐骑、道具坐骑、系统／场景坐骑、炮台、互动配置和其他分类；
- 输入框与选择框最小高度为 `42px`；
- 检索按钮最小高度为 `43px`；
- `Command/Ctrl + K` 聚焦搜索框；
- 搜索完成后默认选中当前排序中的第一条结果；
- 当前选中项同时使用背景变化和左侧朱砂色条。

### 6.4 左侧目录

- 每页显示 `15` 条；
- 单条最小高度 `62px`；
- 名称过长时单行省略；
- 分类与编号位于名称下方；
- 搜索结果右侧不显示资源关系数量；分类与资源自身编号仍显示在名称下方；
- 翻页只替换目录数量、列表和分页，不重载右侧详情；
- 翻页保持页面滚动位置，不跳回顶部；
- 加载时目录降低至 `0.48` 透明度并暂时禁用交互。

### 6.5 详情页眉

- 英文／分类眉题格式为“`分类 DOSSIER`”；
- 宠物页使用实际一级分类，例如“灵兽坐骑 DOSSIER”，不统一写成“宠物 DOSSIER”；
- 资源名称使用朱砂红展示字体；
- 资源名称不设置固定字符宽度，桌面端使用复制按钮之外的全部可用空间；
- 资源内部类型与编号使用等宽字体；
- “复制本页链接”为描边按钮，成功后短暂显示“链接已复制”。

### 6.6 章节标题

章节标题由三部分组成：

```text
方形中文序号  英文眉题
              中文标题
```

序号使用“壹、贰、叁、肆”；坐骑技能内部槽位使用“一、二、三、四、五、六”。

### 6.7 概览表格

- 普通资源概览在桌面端使用三列；
- 宠物概览在桌面端使用两列：“模型”和“宠物外形”并列，“资料备注”和“四维属性”各自横跨整行；
- 字段名和字段值使用与道具说明相同的展示字体，但保留紧凑字号与行高；
- 表格单元格不设置固定高度；
- 字段值由内容自然撑开；
- 长说明字段横跨整行；
- 道具类型只显示说明文字，不显示内部类型编号；
- 道具的说明文本 ID 仅用于内部查找，不在概览中展示；
- 道具的使用效果引用仅用于内部关联，不在概览中展示；
- 宠物属性模板编号不直接展示；概览通过 `pet_model.txt` 显示力量、体魄、元神和筋骨四维值；
- 宠物关联的骑乘配置编号不在概览中展示，关联仍用于坐骑技能和详情链接；
- 宠物概览中的外形字段显示为“宠物外形”；其他资源仍按自身语义使用“角色外形”；
- 宠物概览按“模型、宠物外形、资料备注、四维属性”排列；缺失字段自然省略；
- 称号详情在“概览”之后单独展示“属性加成”，主动属性与被动属性分栏呈现；内部属性编号不展示；
- 购买价格和出售价格无记录时显示 `-`；
- 多行游戏文本保留实际换行。

### 6.8 说明、效果和关系卡片

- 道具说明与使用效果使用同一套展示字体、字号和行高；
- 道具说明采用左侧 `4px` 朱砂边线；
- 已解析效果采用左侧 `3px` 朱砂边线；
- 获得道具、坐骑技能和关联任务通常使用两列卡片；
- 链接悬停只改变边框或浅背景，不使用浮起阴影；
- 页面不显示原始文件路径、行号或“官方说明”前缀；
- 页面不显示“资源关系”独立栏目，双向关系通过使用效果和获得道具链接表达。

### 6.9 空状态

有两类空状态：

1. 栏目为空：使用普通虚线框和次要文字；
2. 搜索无结果：右侧使用方形“空”印记、英文眉题、朱砂色标题和恢复建议。

栏目空状态使用与道具说明相同的展示字体、`16px` 字号和双倍行高。
搜索无结果页面仍使用独立的大型空状态排版。

搜索空状态会按当前资料类型显示：

- 未找到道具；
- 未找到宠物；
- 未找到称号。

若存在搜索词，正文会复述搜索词；否则说明当前分类尚无卷宗。

## 7. 动效与交互反馈

当前动效保持克制：

- 主工作区首次进入时执行 `420ms` 淡入并向上归位 `8px`；
- 顶部标签状态变化为 `160ms`；
- 目录项状态变化为 `140ms`；
- 目录悬停最多向右移动 `2px`；
- 复制链接成功反馈持续约 `1.8s`；
- 页面不使用循环动画、视差或大范围缩放。

当系统启用“减少动态效果”时：

- 关闭平滑滚动；
- 关闭主工作区进入动画；
- 所有过渡时长压缩至 `0.01ms`。

## 8. 响应式规则

### 8.1 `980px` 以下

- 品牌栏高度缩小至 `62px`；
- 品牌印记缩小为 `36px`；
- 顶部标签改为三列两行；
- 主工作区改为单列；
- 索引位于详情上方；
- 目录改为两列；
- 目录奇数项增加右边界以形成网格。

### 8.2 `650px` 以下

- 页面左右边距缩小，主区域宽度为 `calc(100% - 1rem)`；
- 顶部标签改为两列三行；
- 有详情时，详情排在索引之前，优先阅读；
- 目录恢复单列；
- 详情页眉由横向改为纵向；
- 复制按钮移到标题下方；
- 概览、效果、获得道具、技能和任务卡片全部改为单列；
- 资源名称与概况主标题固定为 `28px`；
- 资源概况最小高度改为 `560px`。

## 9. 可访问性

- 页面语言为 `zh-CN`；
- 提供“跳到资料正文”链接；
- 键盘焦点使用 `3px` 青玉色半透明轮廓和 `3px` 偏移；
- 当前页、分页禁用和加载状态不仅依赖颜色；
- 搜索结果数量与右侧搜索空状态使用 `aria-live="polite"`；
- 装饰印记使用 `aria-hidden="true"`；
- 分页、资源类型和资料索引具有明确的导航标签；
- 外链使用 `target="_blank"` 与 `rel="noopener noreferrer"`；
- 移动端主要表单控件接近或达到 `42–43px` 的触控高度；
- 支持系统“减少动态效果”偏好。

## 10. 文案与资料展示原则

- 推测内容不能伪装成已确认事实；
- 原始资料为空时明确显示空状态，不补写未经证实的说明；
- 游戏颜色标签不显示；
- 文本中的 `\n`、`\r` 和 `\t` 转换为实际排版效果；
- 内部类型编号、技能 ID、来源文件和来源行号不在面向玩家的正文中展示；
- 道具说明与使用效果分开；
- 宠物、坐骑和获得道具之间使用可点击链接；
- 任务只通过任务 ID 和轻量交换资料连接，不复制任务数据库；
- 资源概况文案同时涵盖道具、宠物、称号、任务与音乐。

## 12. 后续修改约束

后续调整网页时，应优先遵守以下规则：

1. 不随意替换三类字体角色；
2. 新字号优先复用现有字号变量；
3. 新颜色优先复用现有色彩变量；
4. 新卡片保持方角、细边线和无阴影；
5. 新状态必须同时考虑默认、悬停、当前、空、加载和键盘焦点；
6. 新长文本使用适合中文阅读的行高，不直接继承紧凑界面行高；
7. 宽屏和移动端必须同时验收；
8. 页面布局和文案变更后同步更新本文档与页面测试。
