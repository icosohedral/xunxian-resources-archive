# 寻仙资源存档：当前网页设计说明

> 本文记录当前网站已经落地的页面设计与交互规则，作为后续修改、验收和跨项目对齐的直接依据。  
> 文档基于 2026-11-18 的实际实现整理。当前视觉语言参照本地项目「寻仙GM工作台」
> （`xunxian-gm-tool`）统一；通用原则另见
> [`GENERAL_DESIGN_GUIDELINES.md`](GENERAL_DESIGN_GUIDELINES.md)，两者的差异见第 12 节。

## 1. 产品定位

网站定位为一个可检索、可追溯、适合长期阅读的《寻仙》资料库。

核心气质：

- 清晰、安静、像一个整洁的工作台；
- 与「寻仙GM工作台」保持同一套视觉语言：玻璃顶栏、左侧导航、圆角卡片、青绿主色；
- 全站使用无衬线字体，编号等技术字段使用等宽字体；
- 左侧导航与站点 logo 使用 `public/icons/` 下的图标图片（见第 12 节）；目录列表等其他位置仍用单字方块（物、灵、号……）；
- 装饰只用于建立信息层级，不压过资料本身。

页面最强视觉重点是资源名称或资源概况主文案。主色只用于当前项、主要按钮和小面积强调，避免整页出现多个同等强度的重点。

## 2. 页面结构

### 2.1 全局结构

桌面端采用“顶栏 + 左侧导航 + 资源索引卡片 + 详情卡片”的结构：

```text
┌───────────────────────────────────────────────────────┐
│ [寻] 寻仙资源存档                             ● 今日来访 │  ← 玻璃顶栏
├──────────┬────────────────┬───────────────────────────┤
│ 物 道具   │ 道具索引         │ 资源名称  [分类] [item:1]  │
│ 灵 宠物   │ 搜索与分类       ├───────────────────────────┤
│ 号 称号   │ 1255 条 ‹1/180› │ 概览                       │
│ ──────── │ 目录（条数随高度）├───────────────────────────┤
│ 任 任务 ↗ │ （不滚动）       │ 获得道具 …                 │
│ 乐 音乐 ↗ │                 │                           │
│ v1.1.0 ■■■│                 │                           │
└──────────┴────────────────┴───────────────────────────┘
```

资源概况页不显示资源索引卡片，正文为单张大卡片，与左侧导航顶部、底部对齐。

### 2.2 尺寸

| 区域 | 当前规则 |
|---|---|
| 页面外边距 | 上 `7px`，左右 `9px`，下 `9px`；区块间距 `7px` |
| 顶栏 | 高度 `54px`，圆角 `14px`，吸顶（`top: 7px`） |
| 左侧导航 | 宽度 `202px`，吸顶（`top: 68px`），高度 `calc(100vh - 77px)` |
| 导航项 | 最小高度 `48px`，圆角 `10px` |
| 资源索引卡片 | 宽 `290–350px`；高度与左侧导航相同（`calc(100vh - 77px)`），同样吸顶（`top: 68px`） |
| 资源概况卡片 | 最小高度 `calc(100vh - 77px)`，与左侧导航等高 |
| 详情区 | 占据剩余宽度，卡片之间间距 `10px` |
| 卡片圆角 | 外层卡片 `14px`（`--radius`），内部小卡片 `10px`（`--radius-sm`） |

### 2.3 页面内容

左侧导航共有五项：

1. 道具；
2. 宠物；
3. 称号；
4. 任务（外部网站）；
5. 音乐（外部网站）。

前三项与外部链接之间用一条分隔线隔开；任务与音乐名称后带 `↗`，在新标签页打开。导航项不显示数量。导航底部左侧是网站版本号（点击打开关于弹窗），右侧是配色色块，均不加文字说明。

点击道具、宠物或称号后，右侧默认显示当前列表的第一条资源，并在目录中标为当前项。

资源概况不占用导航项；访问根地址或点击左上角品牌时，默认显示资源概况页。资源概况页只保留：

- 主文案（大标题）；
- 主色浅底的引导文案框；
- 右下角低对比度大型“录”字水印。

资源详情按照资料类型显示：

- 资源名称、分类标签与编号（不提供“复制本页链接”按钮）；
- 概览；
- 道具说明；
- 使用效果；
- 属性加成（称号）；
- 获得道具；
- 坐骑技能；
- 关联任务。

不存在或不适用的栏目不会虚构内容；需要保留栏目时，使用统一的虚线空状态。

## 3. 色彩系统

所有颜色定义在 `public/styles.css` 的 `:root` 中，取值与「寻仙GM工作台」一致。共三套主题：

| 主题 | `<html>` 属性 | 说明 |
|---|---|---|
| 绿色（默认） | 无 | 浅灰绿底、白卡片、青绿主色 |
| 陶土橙 | `data-theme="orange"` | 暖白底、陶土橙主色，实心按钮用砖红 |
| 陶土橙深色 | `data-theme="orange"` + `data-mode="dark"` | 暖炭灰底、珊瑚橙强调 |

### 3.2 使用约束

- 大面积区域只使用 `paper`、`surface`、`rail` 和 `field`；
- 实心主色只用于主要按钮、品牌方块、当前项图标和坐骑技能槽位；
- 主色文字（`pine`）用于卡片标题、关系标签和链接；
- 新组件只使用令牌，不写死颜色，三套主题才能同时生效；
- 状态同时通过底色、描边或位置变化表达，不只依靠颜色。

### 3.3 主题切换

- 切换按钮位于左侧导航底部右侧，三个 `13px` 色块，当前项带描边轮廓，不显示“配色”文字；
- 选择保存在浏览器 `localStorage` 的 `xunxian-archive-color-theme` 键（值为 `green`／`orange`／`dark`）；
- `<head>` 内的内联脚本在样式表加载前读取该值并设置 `<html>` 属性，避免刷新时闪烁；
- 无法使用 `localStorage`（例如无痕模式）时，切换只对当前页面生效；
- 不跟随系统深浅色设置，与工作台一致。

## 4. 字体系统

### 4.1 字体栈

```css
--font-display: "Avenir Next", "PingFang SC", "Microsoft YaHei", sans-serif;
--font-body: Inter, "SF Pro Text", "PingFang SC", "Microsoft YaHei", sans-serif;
--font-data: "SF Mono", "SFMono-Regular", Consolas, "Liberation Mono", monospace;
```

| 字体角色 | 使用目的 |
|---|---|
| 展示字体 | 资源名称、概况主文案、单字方块（物、灵、号、技能槽位……） |
| 正文字体 | 其余全部界面与正文 |
| 数据字体 | 仅用于资源类型与编号（如 `item:12029`） |

项目不加载 Web Font，依赖系统字体；全局设置 `font-synthesis: none`。数量、页码使用正文字体配合 `font-variant-numeric: tabular-nums` 对齐数字。

### 4.2 字号

页面基准为 `13px / 1.6`（与工作台一致）。主要字号：

| 元素 | 字号与特征 |
|---|---|
| 品牌名称 | `16px`、`600` |
| 网站版本（导航左下角） | `11px`、`550`、淡色文字，悬停变为主色 |
| 导航项名称 | `14px`、`700` |
| 卡片标题（索引标题、章节标题） | `13px`、`800`、主色文字 |
| 资源名称 | `clamp(20px, 2.2vw, 26px)`、`700` |
| 概况主文案 | `clamp(22px, 2.6vw, 32px)`、`700`、行高 `1.4` |
| 概况引导文案 | `15px`、`650`、行高 `1.8` |
| 目录资源名称 | `13px`、`700` |
| 目录分类与编号 | `11px` |
| 概览字段名／字段值 | `12px` `600`／`13px` `650` |
| 道具说明 | `14px`、行高 `1.85` |
| 效果、技能说明与引导文字 | `13px`、行高 `1.75–1.8` |
| 按钮与输入框 | `12–13px`、`700`（按钮） |

长段落说明使用 `1.75–1.85` 行高；界面控件使用紧凑行高。

## 5. 形状、边框与间距

### 5.1 形状

- 顶栏、导航、外层卡片使用 `14px` 圆角；
- 内部小卡片（字段格、效果、获得道具、技能、任务）使用 `10px` 圆角；
- 按钮与输入框使用 `9px` 圆角，分页按钮 `8px`；
- 单字图标方块使用 `7–9px` 圆角；状态与标签使用全圆角胶囊；
- 普通区域使用 `1px solid` 边框；未解析内容和空状态使用虚线边框；
- 外层卡片带很浅的阴影（`--card-shadow`）；弹窗使用较重阴影（`--shadow-lg`）。

### 5.2 间距

- 卡片标题栏高度 `52–54px`，左右内边距 `16px`，底部一条分隔线；
- 卡片内容左右内边距 `18px`（`650px` 以下 `14px`）；
- 内部小卡片之间间距 `8–10px`，内边距 `10–12px`；
- 详情卡片之间间距 `10px`。

## 6. 核心组件

### 6.1 顶栏

- 半透明白底（`--glass`）加 `18px` 背景模糊，吸顶；
- 左侧为 `34px` 站点 logo（`public/icons/logo.png`，葫芦），无底色，带轻微投影；
- 浏览器标签页图标（favicon）同样使用 `public/icons/logo.png`；
- 品牌旁不显示版本号，版本号位于左侧导航左下角（见 6.2）；
- 右侧只显示“今日来访”；不再提供“关于网站”按钮，关于弹窗只从左下角版本号打开（见 6.10）；
- 右侧“今日来访”为带状态点的胶囊，显示按中国时区统计的匿名浏览器数量；同一浏览器同一天只计一次，统计存入独立数据库，不写入资源目录；
- 不显示宣传语。

### 6.2 左侧导航

- 每项为“`28px` 图标 + 名称”，不显示数量；图标在 `public/icons/`：道具 `items.png`、宠物 `companions.png`、称号 `title.png`、任务 `quests.png`、音乐 `music.png`（原图为 `assets/image/` 第 2 套）；图标不加底框，带轻微投影；
- 悬停：浅底色、文字加深；
- 当前项：主色浅底、主色文字，图标放大到 `1.08` 倍（悬停时同样放大）；深色模式下另加一圈描边；
- 底部左侧为版本号按钮（当前 `v1.1.0`，版本序列从 `v1.0.0` 开始），参照工作台写法：无边框淡色小字，`aria-label` 为“关于寻仙资源存档，版本 …”，点击打开关于弹窗；底部右侧为配色色块；
- 任务与音乐在名称后显示 `10px` 的右上箭头（CSS mask 内联 SVG，颜色取 `--ink-faint`，不依赖字体），在新标签页打开，不显示“外链”字样；
- 导航内容超出高度时可在导航内滚动。

### 6.3 搜索与筛选

- 索引卡片标题按当前导航显示为“道具索引”“宠物索引”或“称号索引”；
- 搜索框左侧带放大镜图标，占位文字为“输入道具名称”“输入宠物名称”或“输入称号名称”；
- 道具、宠物和称号拥有相互独立的检索入口；
- 道具可筛选“普通道具”和“任务道具”；
- 宠物可按侍宠、灵兽坐骑、道具坐骑、系统／场景坐骑、炮台、互动配置和其他分类；
- 称号可按上级分类或具体称号分组筛选；上级分类名称由资料库归纳（筛选框下方不再显示说明文字）；
- 输入框与选择框高度 `36px`，聚焦时主色边框加焦点光圈；
- 检索按钮为实心主色按钮，高度 `36px`，文字随当前分类显示为“检索道具”“检索宠物”或“检索称号”；
- `Command/Ctrl + K` 聚焦搜索框；
- 点击道具、宠物、称号，或搜索、切换分类后，都默认选中当前排序中的第一条结果；没有结果时显示搜索空状态。

### 6.4 资源目录

- 每页条数随窗口高度变化：索引卡片放得下几条，一页就显示几条，目录本身不滚动且正好填满卡片（见 6.4.1）；基准行高 `52px`，圆角行；
- 每行为“单字方块 + 名称 + 分类与编号”，名称过长时单行省略；
- 当前项：主色浅底、内描边、实心主色单字方块、强调色名称；
- 索引卡片与左侧导航等高，页面滚动时卡片保持吸顶；
- 目录上方灰底栏左侧显示结果总数，右侧为翻页：`‹ 第 1 / 3347 页 ›`，箭头为 `26px` 描边方块按钮（`aria-label` 为“上一页／下一页”），不可用时显示为禁用样式；卡片底部不再单独放分页；
- 翻页只替换结果栏与目录，不重载右侧详情，保持页面滚动位置；
- 加载时目录降低至 `0.48` 透明度并暂时禁用交互。

#### 6.4.1 每页条数

- 浏览器在页面加载和窗口尺寸变化（`200ms` 防抖）时，按基准行高 `52px`（CSS 变量 `--row-base`）计算目录能放下的整行数 `n`，并让目录正好填满卡片、底部不留空白：
  - 剩余空间不少于半行，且放 `n + 1` 行时每行高度不低于基准的 `90%`（压缩不超过 10%，约 `47–51px`），就多放一行并略压低行高；
  - 否则保持 `n` 行，把剩余空白平均分给每一行，行高略高于 `52px`；
  - 计算出的行高写入目录元素的 `--row-height`（向下取到 `0.01px`），行高度为 `var(--row-height, var(--row-base))`，行内容垂直居中；翻页只替换目录内容，新一页沿用同样的行高；
- 结果写入 Cookie `xunxian-archive-page-size`（路径 `/`，有效期一年），服务器（本地 `app.py` 与线上 `entry.py` 相同逻辑）按它输出每页条数；
- Cookie 缺失或不是数字时每页 `15` 条；有效值限制在 `4–40`；
- 首次访问或窗口尺寸变化导致条数不同时，只局部刷新目录一次，并换算页码，使原来当前页的第一条仍在新的一页中；这次刷新用 `replaceState`，不新增浏览器历史；
- 索引卡片（`.index-rail`）上带 `data-page-size` 与 `data-page`，供脚本换算页码；
- `900px` 以下目录随页面滚动，不重新计算，沿用最近一次保存的条数；
- `/api/search` 接口仍固定每页 `15` 条。

### 6.5 详情页眉

- 独立卡片，只显示资源名称与其下方的标签，不提供“复制本页链接”按钮；
- 名称下方是分类标签（主色浅底胶囊，宠物显示实际一级分类，例如“灵兽坐骑”）和编号胶囊（等宽字体，如 `pet:1534`）；
- 模板中仍保留“`分类 DOSSIER`”眉题文字，但视觉上隐藏（见 6.6）；

### 6.6 章节卡片

每个章节是一张卡片：

```text
┌────────────────────────────┐
│ 概览                        │  ← 标题栏：主色标题
├────────────────────────────┤
│ 内容                        │
└────────────────────────────┘
```

- 章节标题不使用“壹、贰、叁、肆”等序号标记；坐骑技能内部槽位仍使用“一、二、三……”，放在实心主色方块中；
- 英文眉题（`KNOWN FIELDS` 等）保留在模板中供读屏使用，视觉上隐藏。

### 6.7 概览字段

- 每个字段是一个浅底圆角小卡片，字段名在上、字段值在下；
- 普通资源桌面端三列，`1100px` 以下两列；
- 宠物概览两列：“模型”和“宠物外形”并列，“资料备注”和“四维属性”各自横跨整行；
- 长说明字段横跨整行；字段值由内容自然撑开；
- 道具类型只显示说明文字，不显示内部类型编号；
- 道具的说明文本 ID 与使用效果引用仅用于内部关联，不在概览中展示；
- 宠物属性模板编号不直接展示；概览通过 `pet_model.txt` 显示力量、体魄、元神和筋骨四维值；
- 宠物关联的骑乘配置编号不在概览中展示，关联仍用于坐骑技能和详情链接；
- 宠物概览中的外形字段显示为“宠物外形”，其他资源使用“角色外形”；
- 购买价格和出售价格无记录时显示 `-`；
- 多行游戏文本保留实际换行。

### 6.8 说明、效果和关系卡片

- 道具说明为浅底圆角框，`14px` 正文；
- 已解析效果为浅底圆角框，效果名使用主色文字；
- 效果目标、获得道具和关联任务为白底圆角卡片，顶部一行主色小字标注关系，悬停时浅底色与描边加深；
- 称号属性加成分“主动属性／被动属性”两张卡片，属性两列排列，属性值使用主色文字；属性为奇数个时最后一项占满整行；
- 获得道具、坐骑技能和关联任务桌面端使用两列；
- 页面不显示原始文件路径、行号或“官方说明”前缀；
- 页面不显示“资源关系”独立栏目，双向关系通过使用效果和获得道具链接表达。

### 6.9 空状态

1. 栏目为空：虚线圆角框，居中淡色文字；
2. 搜索无结果：右侧独立卡片，居中显示主色浅底“空”字方块、“未找到道具／宠物／称号”标题和恢复建议；左侧目录同样显示“空”字方块和“没有找到卷宗”。

若存在搜索词，正文会复述搜索词；否则说明当前分类尚无卷宗。

### 6.10 关于弹窗

与工作台的关于弹窗一致：

- 原生 `<dialog>`，宽 `430px`，白底、`16px` 圆角、`--line-strong` 边框、`--shadow-lg` 阴影；遮罩为 `--overlay` 加 `3px` 模糊；
- 标题为“寻仙资源存档 v版本号”，`15px` 粗体，无关闭“×”；
- 正文只有一条浅底圆角信息行：GitHub 图标 + “项目地址” + 仓库链接（不显示作者维护与特别鸣谢）；
- 其下是一段浅底说明框（非官方站点与版权声明）；
- 底部灰底操作栏，右侧一个实心主色“知道了”按钮；
- 打开时焦点移到“知道了”；按 Esc、点“知道了”或点遮罩均可关闭，关闭后焦点回到打开它的按钮，且不滚动页面。

## 7. 动效与交互反馈

- 内容区首次进入时执行 `280ms` 淡入并向上归位 `6px`；
- 弹窗打开时 `160ms` 淡入上移并轻微放大；
- 按钮、导航、目录等状态变化为 `130–140ms`；
- 页面不使用循环动画、视差或大范围缩放。

当系统启用“减少动态效果”时：关闭平滑滚动、关闭进入与弹窗动画，所有过渡时长压缩至 `0.01ms`。

## 8. 响应式规则

### 8.1 `1100px` 以下

- 概览字段改为两列。

### 8.2 `900px` 以下

- 左侧导航改为位于顶栏下方的导航卡片（参照音乐站），不再吸顶：
  - 第一行四等分：道具、宠物、称号和“更多”按钮，图标 `24px`，内容居中；
  - 任务、音乐默认折叠；点“更多”展开为第二行两等分（再点收起），按钮箭头翻转，`aria-expanded` 同步；
  - 版本号与配色色块另起一行，左右分列，上方一条浅分隔线；
- 桌面端不显示“更多”按钮，任务与音乐常驻；
- 资源索引卡片位于详情上方，内容区改为单列；索引卡片取消固定高度与吸顶，目录随页面展开，不裁切。

### 8.3 `650px` 以下

- 页面外边距与间距缩小为 `6px`，顶栏高度 `50px`；
- 顶栏隐藏“今日来访”；
- 采用“列表 → 详情”两层，同一时间只显示一层：
  - 列表层：打开道具、宠物、称号或检索时，服务端照常默认选中第一条，但会给 `.archive-shell` 加 `is-auto-selected`；手机端据此隐藏详情，只显示搜索与目录，索引卡片占满整行宽度；
  - 详情层：点条目或直接打开 `/resources/…` 时没有该标记，手机端隐藏索引，只显示详情；
  - 详情顶部显示“‹ 返回××列表”（有关键词时为“返回搜索结果”），链接到同一筛选和页码的列表；若从本站列表进入，点击时改用浏览器后退，保留原来的滚动位置；
  - 返回按钮在 `650px` 以上隐藏，桌面端与平板端布局不受影响；
- 详情页眉内边距缩小；
- 概览、效果、获得道具、属性、技能和任务全部改为单列；
- 资源概况最小高度改为 `460px`。

## 9. 可访问性

- 页面语言为 `zh-CN`；
- 提供“跳到资料正文”链接；
- 键盘焦点使用 `3px` 主色半透明轮廓（`--focus-ring`）和 `2px` 偏移；
- 当前页、分页禁用和加载状态不仅依赖颜色；
- 搜索结果数量与右侧搜索空状态使用 `aria-live="polite"`；
- 装饰单字和“录”字水印使用 `aria-hidden="true"`；英文眉题视觉隐藏但保留给读屏；
- 主题色块为带 `aria-label` 与 `aria-pressed` 的按钮，组带 `aria-label="颜色主题"`；
- 分页、资源类型和资料索引具有明确的导航标签；
- 外链使用 `target="_blank"` 与 `rel="noopener noreferrer"`；
- 支持系统“减少动态效果”偏好。

## 10. 文案与资料展示原则

- 推测内容不能伪装成已确认事实；
- 原始资料为空时明确显示空状态，不补写未经证实的说明；
- 游戏颜色标签不显示；
- 文本中的 `\n`、`\r` 和 `\t` 转换为实际排版效果；
- 内部类型编号、技能 ID、来源文件和来源行号不在面向玩家的正文中展示；
- 道具说明与使用效果分开；
- 宠物、坐骑和获得道具之间使用可点击链接；
- 任务只通过任务 ID 和轻量交换资料连接，不复制任务数据库；
- 资源概况文案同时涵盖道具、宠物、称号、任务与音乐；
- 导航与 logo 图标经维护者确认随网站发布，放在 `public/icons/`（`public/README.md` 记有这一例外），通过 `/static/icons/…` 访问；Worker 构建会把整个 `public/` 复制进静态资源。其他游戏图片仍不放入仓库，目录列表仍使用单字方块。

## 12. 与通用设计原则的差异

[`GENERAL_DESIGN_GUIDELINES.md`](GENERAL_DESIGN_GUIDELINES.md) 建议避免玻璃拟态、慎用圆角卡片和阴影。当前网站为与「寻仙GM工作台」保持一致，有意作出以下例外：

- 顶栏使用半透明玻璃背景；
- 主要区块使用 `14px` 圆角卡片；
- 外层卡片带很浅的阴影。

除此之外仍遵守通用原则：不使用大面积渐变和高饱和色，阴影保持极浅，重点只有一处。

## 13. 后续修改约束

1. 新颜色只使用现有令牌，并在三套主题下都检查；
2. 若工作台的设计令牌调整，优先同步本项目以保持一致；
3. 新卡片沿用“标题栏 + 内容”结构与现有圆角层级（外层 `14px`、内部 `10px`）；
4. 新状态必须同时考虑默认、悬停、当前、空、加载和键盘焦点；
5. 新长文本使用适合中文阅读的行高，不直接继承紧凑界面行高；
6. 宽屏、`900px` 以下和手机宽度必须同时验收；
7. 页面布局和文案变更后同步更新本文档与页面测试。
